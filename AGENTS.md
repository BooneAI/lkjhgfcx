# Agent Instructions

This repository uses Gatsby with CSS modules. When editing files under this repository:

- Prefer existing layout components (`Layout`, `Container`, `Blog`) for blog pages and keep alt text for images meaningful.
- Keep blog metadata in `src/helpers/blog.json` in sync with the actual page path.
- Use CSS Modules for styling rather than inline styles; favor responsive adjustments at the bottom of the file.
- Run `npm run build` when feasible; if a check cannot be run, call it out in the final summary.
- Update or add citations in final responses for any files you modify.
